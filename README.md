# User Registration Form

This workspace contains a simple browser-based user registration form with client-side validation and a localStorage demo.

Files:

- [register.html](register.html) — the registration form you can open in your browser.

How to use:

1. Open `register.html` in your browser (double-click the file or drag it into the browser).
2. Fill the form and click **Register**.
3. Click **Show stored users** to view saved users in `localStorage`.

No server is required; this is a static demo.
